# Three DAC technologies instead of one

Direct air capture is modelled as three technologies, solid sorbent DAC, liquid solvent DAC and RepAir, instead of one generic DAC, because they use different energy carriers and have different cost structures, and that decides where and when each one is built and run. Values are the average case of the DAC input recap (EUR2015, one set per vintage for 2030, 2040 and 2050). Solid sorbent replacement is covered by the 4 % fixed O&M rather than a separate variable cost, which removes a double count in the earlier data. Liquid solvent DAC uses an electrified calciner, so it consumes electricity only. RepAir has one input set per vintage because its electricity use falls between technology generations.

## Consequences

- Solid sorbent DAC takes its heat from the local district heating at the area's heat price, so it is sited where heat is cheap and may sit away from storage sites.
- The optimistic and pessimistic cases stay in the input recap and are not in the model data.
